# Ingredient artwork

Generated with the built-in ImageGen tool, using the user's ingredient screenshot as visual direction. Original: `public/ingredients/atlas.png`. The 48 equal cells are exported as JPG assets for ingredient cards and order summaries.

Generation brief: one production sprite atlas for a pizza ingredient picker, exactly eight columns and six rows, equal square cells, landscape 4:3, top-down realistic food photography, white background, no labels or UI. Each food centered with padding.

Row order:
1. Classic, wholegrain and gluten-free pizza bases; tomato, cream, pesto and BBQ sauces; cucumber.
2. Grated mozzarella, sliced mozzarella, parmesan, cheddar, gorgonzola, burrata, ricotta, feta.
3. Cherry tomatoes, tomato slices, red/yellow/green peppers, red onion, arugula, basil.
4. White mushrooms, porcini, artichokes, black/green olives, corn, sundried tomatoes, pineapple.
5. Salami, ham, bacon, chicken, tuna, shrimp, anchovies, pepperoni.
6. Chilli, jalapeños, spinach, oregano, capers, halved cherry tomatoes, pine nuts, rosemary.
